- erro de português;
- japonês incorreto;
- tradução estranha;
- informação incompleta;
- link quebrado;

[Reportar um problema →](LINK_PLACEHOLDER)

Explica:

- qual página tem o problema;
- o que está errado;
- qual seria a correção, se souberes;
- uma fonte, se tiveres.

## Quero editar uma página

### 1. Cria uma conta no GitHub

Acede ao GitHub e cria uma conta gratuita.

### 2. Abre o repositório da 日本語 Wiki

[Repositorio da wiki →](LINK_PLACEHOLDER)

### 3. Encontra a página

Os artigos são ficheiros Markdown (`.md`).

Procura o ficheiro correspondente à página que queres melhorar.

### 4. Edita

No GitHub, abre o ficheiro e seleciona a opção de edição.

Faz apenas as alterações necessárias.

### 5. Explica o que alteraste

Escreve uma mensagem curta dizendo o que corrigiste.

Por exemplo:

`Corrige leitura de 優しい`

### 6. Cria um Pull Request

Envia a alteração como Pull Request.

A edição será revista antes de entrar na wiki.

## Quero adicionar conteúdo novo

Antes de criar uma página nova, verifica se ela ainda não existe.

Segue o padrão das páginas semelhantes.

A 日本語 Wiki procura manter consistência entre:

- leituras;
- traduções;
- exemplos;
- origem;
- notas de uso;
- estruturas;
- ligações internas.

Se tiveres dúvidas, abre uma Issue antes de começar.

## Preciso saber japonês avançado?

Não.

Existem muitas formas de ajudar:

- corrigir português;
- encontrar links quebrados;
- melhorar formatação;
- adicionar fontes;
- verificar exemplos;
- sugerir explicações melhores;
- revisar conteúdo;
- adicionar informação que esteja em falta.

---

## Revisão

Contribuições não são publicadas automaticamente.

Antes de entrar na wiki, uma alteração pode ser revista para verificar:

- precisão do japonês;
- qualidade das fontes;
- clareza da explicação;
- consistência com o resto da wiki.

Isto ajuda a evitar que informação incorreta seja ensinada a outros estudantes.
